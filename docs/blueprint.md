# **App Name**: Farah Nisa Portfolio

## Core Features:

- Portfolio Showcase: Display personal projects, skills, and experience.
- Featured Project: Showcase the 'Kuiz Belanjawan 2026' project with description, screenshots, and a link to the live demo.
- Contact Form: Allow visitors to send an email via a contact form that utilizes a backend function and SendGrid.
- Email Copy: Enable one-click copying of the email address to the clipboard.
- Visitor Counter: Track total and unique visitors using Firestore and Cloud Functions for backend-safe increment and display a live count.
- AI Content Generator Integration Guidance Tool: LLM helps select highlights from completed AI Content Generator integrations to share.
- Astro Awani Contributions: Showcase Astro Awani contributions, built features and technical highlights in a dedicated section.

## Style Guidelines:

- Primary color: Dusty pink (#D8B4A0) for a warm, inviting feel.
- Background color: Soft beige (#F5F5DC) as a neutral backdrop.
- Accent color: Warm neutral (#A39788) for highlighting important elements and calls to action.
- Body text font: 'Inter', a sans-serif font for clean and modern readability.
- Headline text font: 'Space Grotesk', a sans-serif font for a bold and technological feel.
- Simple, line-based icons for key sections and actions, maintaining a clean aesthetic.
- Mobile-first, responsive layout with clear section separation and a single-page structure.
- Subtle animations for transitions and interactions, ensuring accessibility with reduced-motion options.
